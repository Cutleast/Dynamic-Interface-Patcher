= Dynamic Interface Patcher
:description: Patch Skyrim UI mods locally without redistributing protected assets.

Dynamic Interface Patcher (DIP) is an automated patching tool for Skyrim UI mods with
restrictive asset permissions, such as RaceMenu or MiniMap.

DIP applies compatible patches locally. Original assets and files are not redistributed.
Compatible patches can be found on Nexus Mods by searching for "DIP Patch".

WARNING: You are responsible for respecting the permissions of every original mod. Do not
redistribute patched files unless the relevant permissions explicitly allow it.

== Features

* Fully automated patching
* Automatic BSA extraction
* Installation as a mod in Mod Organizer 2 or Vortex
* Command-line arguments for automated patching

== How it works

. DIP copies the original mod into a temporary directory.
. It extracts BSA archives when required.
. It patches shapes.
. It converts SWF files to XML.
. It applies XML changes from the patch definition.
. It converts the XML files back to SWF.
. It copies the patched mod back to the selected directory.
