== Description

Dynamic Interface Patcher (DIP) applies compatible patches to Skyrim UI mods locally. It is
designed for mods with restrictive asset permissions, such as RaceMenu or MiniMap, whose
original files must not be redistributed as part of a compatibility patch.

DIP combines the original mod and a small compatible patch on your computer. The original
assets therefore remain with their author and are never included in the distributed DIP patch.

== Features

* Fully automated patching
* Local processing without redistributing protected assets
* Automatic extraction of required BSA archives
* Installation through Mod Organizer 2 or Vortex
* Graphical patch selection and execution
* Command-line support for automated patching
* Dedicated patch creator for authors of compatibility patches

WARNING: You are responsible for respecting the permissions of every original mod. Do not
redistribute patched files unless the relevant permissions explicitly allow it.
