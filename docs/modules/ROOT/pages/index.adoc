= Dynamic Interface Patcher
:description: Patch Skyrim UI mods locally without redistributing protected assets.

Dynamic Interface Patcher (DIP) applies compatible patches to Skyrim UI mods locally.

== Overview

* *Purpose:* Patch UI mods with restrictive asset permissions, such as RaceMenu or MiniMap.
* *Asset handling:* Original assets and files are processed locally and are not redistributed.
* *Automation:* DIP extracts required BSA archives, patches shapes and SWF data, and produces
  the patched output automatically.
* *Mod-manager support:* DIP can be installed as a mod in Mod Organizer 2 or Vortex.
* *Command-line support:* Patches can run without manual interaction with the graphical
  interface.
* *Compatible patches:* Search Nexus Mods for "DIP Patch" to find supported patch packages.

WARNING: You are responsible for respecting the permissions of every original mod. Do not
redistribute patched files unless the relevant permissions explicitly allow it.
